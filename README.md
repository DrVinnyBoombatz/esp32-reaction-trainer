# esp32-reaction-trainer
An ESP32-powered reaction time training system using arcade buttons and LEDs.
Overview

A reaction training system built with an ESP32, arcade buttons, and LEDs. The system randomly activates a target, records the user's reaction time, and can be expanded into a multi-target training platform.

Features
Random LED activation
Reaction time measurement
Arcade button input
Serial Monitor statistics
Expandable to 4+ targets
Future Bluetooth support
Data logging
Mobile app integration
Hardware

Breadboard

LEDs
